# Genesis Love

### Christian Dating & Relationship Platform

Genesis Love is a mobile-first Christian dating and relationship platform designed around intentional connections, relationship-focused experiences, and community features.

This repository is a **public portfolio showcase** and does not contain private production source code or sensitive configuration.

## Product Experiences

- account creation and authentication
- profiles
- matching
- invitations
- speed-dating experiences
- relationship-focused interactions
- community features
- mobile-first responsive flows

## Product Direction

The current product is web-based and mobile-first, with native iOS and Android experiences planned.
